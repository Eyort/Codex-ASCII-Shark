# 草浪动画实验回顾

## 实验目的

在现有 ASCII 鲨鱼背景之外，尝试增加一个可选草浪动画。两种效果设计为互斥切换，避免同时叠加；草浪参考用户提供的草地图，目标是形成带有图像色彩和明暗纹理的 ASCII 波浪。

## 实现思路与技术

- 使用 TypeScript，沿用项目原有的本地设置服务、页面定位与可撤销注入流程。
- 把本地草地图打包进注入器，在动画初始化或尺寸/细节变化时，用 Canvas 2D 采样图像并生成彩色 ASCII 纹理。
- 将生成结果缓存为纹理，再切分成有上限的 CSS 波浪条带，通过缓慢的 transform 动画营造整体起伏。
- 采用最多 24 条波浪层，不创建十几万根独立草叶，也不引入 Three.js/WebGL 或逐帧 JavaScript 绘制循环，以降低额外依赖和持续负载。
- 在设置页试做了动画类型、草浪细节、颜色、透明度、速度、暂停和总开关；运行时切换会销毁前一种动画再创建另一种。

## 遇到的问题及处理

- **大面积纹理容易显得拥挤。** 调整了 ASCII 字符间距、图像采样、整体透明度和波浪层数量，减弱密度与对比度。
- **预览设置与注入器读取的配置位置不一致。** 排查后确认开发预览可能连到不同工作目录；改为确认预览与运行中的本地配置服务指向同一项目实例。
- **页面识别规则曾漏掉部分对话模式。** 将注入限制在可识别的主内容区和输入区域，并扩展已支持模式的识别，同时保留无法确认页面时安全跳过的行为。
- **设置项随动画类型切换时曾被隐藏。** 修正条件显示，恢复公共设置和鲨鱼专属设置的可见性。
- **草浪即使降低密度后仍覆盖了很大一片聊天背景。** 性能优化无法改变这个效果本身的视觉占比与质感。

## 最终取舍

用户实际查看后认为整片覆盖的草浪不够好看，因此决定从当前项目中完整移除。继续调低透明度或密度只能减轻覆盖感，不能让它达到用户希望的效果。项目保留原有鲨鱼动画及其数量、颜色、透明度、速度、暂停和开关设置；草浪界面、运行代码、图片资源、配置字段和专属测试均已删除。

## 当前项目状态

当前运行版本只包含 ASCII 鲨鱼背景。旧本地配置即使残留草浪字段，配置读取也会忽略未知字段；示例配置和双语 README 不再提及草浪。该回顾仅记录一次已结束的实现实验，不代表草浪仍是可用功能。
